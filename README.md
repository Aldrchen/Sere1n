# Sere1n · 个人主页

> 纯静态、零依赖、部署在 GitHub Pages 的个人主页 + 管理后台

## 📁 文件结构

```
Sere1n/
├── index.html    ← 访客看到的主页
├── admin.html    ← 你用来改内容的管理后台
├── data.json     ← 数据文件（admin 读写，主页读取）
└── README.md     ← 本文件
```

## 🚀 部署步骤

1. 把这 4 个文件放到 GitHub 仓库根目录
2. Settings → Pages → Source: main 分支 → Save
3. 等待 2-3 分钟
4. 主页：`https://你的用户名.github.io/Sere1n/`
5. 管理后台：`https://你的用户名.github.io/Sere1n/admin.html`

## 🔧 管理后台使用

### 首次配置
1. 打开 `admin.html`
2. 左侧选「数据管理」→ 选「远程模式」→ 保存 GitHub Token
3. Token 获取：GitHub → Settings → Developer settings → Personal access tokens → Generate new token → 勾选 `repo`

### 改内容
| 左侧菜单 | 能改什么 |
|---|---|
| 背景图 | 上传图片 / 填URL / 调模糊度透明度 / 6款预设渐变 |
| 主题色 | 8套配色一键切换 |
| 模块开关 | 显示/隐藏任意板块 |
| 自定义代码 | 写CSS改样式 / 写HTML加内容 |
| 个人资料 | 姓名/方向/城市/职业/爱好/头像/简介 |
| 技能管理 | 增删改 + 百分比 |
| 项目管理 | 增删改项目卡片 |
| 生活碎片 | 增删改兴趣标签 |
| 社交链接 | GitHub/邮箱/微信/IG/小红书 |
| 数据管理 | 导入/导出/恢复默认/切换模式 |

## 🎨 背景图说明

支持三种方式：
1. **上传图片** → 自动转 base64，无需图床
2. **网络URL** → 填图床链接
3. **预设渐变** → 6款深色渐变一键切换

参数调节：
- 模糊度 0~60px（越大越朦胧）
- 透明度 0~1（越小越暗）
- 缩放 1x~2x（防止边缘露白）

## 📱 移动端

主页和管理后台都做了移动端适配，手机可直接编辑。

## ⚠️ 注意

- 改完内容点对应「保存」按钮才会生效
- 主页打开有约 30 秒缓存延迟，强刷 Ctrl+F5
- Token 只存在浏览器本地，换浏览器需重新输入
- 建议定期「导出数据」做备份
