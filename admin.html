🖼️ 怎么换背景图？

1. 点左侧「背景图」→ 点上传区域选图片（自动转base64，无需图床）
2. 或粘贴网络图片URL到输入框
3. 调整模糊度和透明度滑块
4. 点「保存背景设置」→ 打开主页刷新即可看到

🎨 怎么换主题色？

点左侧「主题色」→ 点击你喜欢的配色卡片 → 自动保存

📝 怎么改文字内容？

左侧「个人资料」「技能管理」「项目管理」等 → 修改后点对应保存按钮

🔑 Token 怎么获取？

1. 登录 GitHub → 右上角头像 → Settings
2. 左侧最底部 → Developer settings → Personal access tokens → Tokens (classic)
3. Generate new token → Note 填"Sere1n" → Expiration 选"No expiration"
4. 勾选 repo → Generate token
5. 复制 ghp_ 开头的字符串 → 回到这里粘贴保存

💡 不想用 Token 怎么办？

在「数据管理」里点「本地模式」→ 所有修改存在浏览器里
缺点：换浏览器/清缓存数据会丢失，需要重新配置
